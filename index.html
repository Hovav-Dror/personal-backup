rclone — Personal Documents Backup

This is a private, single-user backup configuration using rclone on its owner’s Mac to back up selected Documents files to the owner’s Google Drive.

Google authorization allows the locally running backup tool to transfer files and inspect the destination as needed for backup operations. This is not a public backup service and is not offered to other users.

This website provides information about the configuration. It does not provide access to backup files or Google authorization credentials.

Privacy policy

For support, use the support email shown on the Google authorization screen.
