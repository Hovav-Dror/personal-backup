Personal Documents Backup home

Privacy policy

This policy describes the private rclone configuration identified as rclone — Personal Documents Backup.

Data access and use

The configuration uses Google authorization to back up selected Documents files from its owner’s Mac to the owner’s Google Drive. Backup operations can access file contents and metadata, including names, sizes and modification times.

The configured Google Drive permission is broader than the selected Documents backup. The backup selection is a local configuration, not a Google permission restriction.

Storage and sharing

Backup copies are stored in the owner’s Google Drive. Authorization credentials and operational information are retained locally for the backup’s operation.

The configuration is for the owner’s personal use. It does not sell Google user data or use it for advertising. This informational website does not receive backup contents or authorization credentials.

Control and deletion

The owner controls the backup configuration and stored copies. Google access can be revoked through the Google account’s connected-app settings. Revoking access prevents further authorized access; it does not itself delete existing backup copies. Those copies must be managed separately in Google Drive.

Website hosting

These informational pages are hosted by GitHub Pages. GitHub records visitors’ IP addresses for security purposes under its privacy statement. The pages contain no additional analytics or tracking scripts.

For questions, use the support email shown on the Google authorization screen.
